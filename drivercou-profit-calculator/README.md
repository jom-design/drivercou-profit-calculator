# حاسبة عدالة المشاوير — Driver Profit Calculator

تطبيق ويب عربي مجاني لحساب ربحية رحلات Uber وDiDi وinDrive.

## التشغيل
يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:
```bash
npm run build
npm run preview
```

## الوظائف الموجودة
- حاسبة ربحية فورية.
- إعدادات الوقود والاستهلاك والصيانة والحد الأدنى للربح.
- قرار قبول / مراجعة / رفض.
- سجل رحلات محلي عبر IndexedDB.
- تقارير ومقارنة التطبيقات.
- رفع صورة واستخراج أولي للنص عبر Tesseract.js (عربي + إنجليزي).
- مراجعة بيانات OCR يدويًا قبل نقلها للحاسبة.
- تصدير CSV ونسخة احتياطية JSON واستيرادها.
- نطق القرار عند دعم المتصفح.
- PWA وService Worker مبدئي.
- تصميم Responsive للتابلت أفقيًا ورأسيًا.

## ملاحظات مهمة قبل الإنتاج
1. OCR العربي يختلف حسب جودة الصورة وتخطيط التطبيق. يجب مراجعة الأجرة والمسافات والوقت يدويًا دائمًا.
2. قواعد OCR الحالية أولية وليست قواعد إنتاج معتمدة لكل إصدار من Uber أو DiDi أو inDrive.
3. التقاط شاشة التطبيقات الأخرى مباشرة غير مدعوم من صفحة ويب Android عادية. يحتاج Android Native MediaProjection بموافقة المستخدم.
4. أرقام البنزين والإعدادات الافتراضية قابلة للتغيير من صفحة الإعدادات؛ راجعها حسب أسعارك الفعلية.
5. مثال الاختبار المرجعي: 22 كم، أجرة 165، 40 دقيقة، ينتج تكلفة وقود 48.95، صيانة 55، إجمالي تكلفة 103.95، صافي 61.05، ربح ساعة 91.58.
6. لا يوجد Backend. البيانات محفوظة على نفس المتصفح والجهاز. صدّر نسخة احتياطية بانتظام.
7. الـ manifest يحتاج أيقونات فعلية قبل النشر النهائي على المتاجر.

## ملاحظة حول العمولة
- Uber يُعامل كصافي فقط إذا تأكد المستخدم أن المعروض هو صافي رسوم الخدمة.
- inDrive وDiDi يبدأان بحالة "غير متأكد"، ولا يتم خصم عمولة تلقائيًا.
- يمكن تحديد الأجرة إجمالية وإدخال نسبة العمولة.
